# Netflix Movies Data Analysis

## Project Overview
This project analyzes the Netflix movies dataset using Python and Jupyter Notebook. The goal is to extract meaningful insights and visualize trends from the dataset.

## Objectives
- Clean and preprocess data
- Explore movie trends
- Analyze ratings and categories
- Generate visualizations
- Extract useful business insights

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
Netflix Movies Dataset

## Analysis Performed
- Data Cleaning
- Handling Missing Values
- Statistical Analysis
- Visualization
- Trend Analysis
